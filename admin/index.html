Promotional emails

Sends one email to each client who has turned on Promotional Alerts in the app. It is sent from your own Gmail account, so nothing extra to pay.
One-time Gmail setup
  1. Go to console.cloud.google.com, create a project and open APIs & Services → Library. Enable the Gmail API.
  2. OAuth consent screen: choose External, fill in the app name, and under Test users add kottonkandybeautybar4@gmail.com (the Gmail you send from).
  3. Credentials → Create credentials → OAuth client ID → type Web application. Under Authorized JavaScript origins add http://localhost:8000.
  4. Copy the Client ID and paste it below.

Gmail lets a normal account send about 500 emails a day. Only clients who opted in are emailed. Do not email people who did not agree to marketing.

Nearest PUDO lockers
